# منصة د. نور محمد الرقمية (Dr. Nour Mohamed Digital Platform)

منصة رقمية متكاملة مخصصة لأخصائية التغذية والمدربة الشخصية **د. نور محمد**، تهدف إلى إدارة الاستشارات، حجز جلسات التغذية والتدريب، عرض المنتجات الرقمية (PDF)، وتقديم خطط العضويات الخاصة.

## هيكل المشروع (Project Structure)
```text
dr-nour-platform/
├── index.html            # الصفحة الرئيسية
├── book.html             # صفحة حجز الاستشارات والتدريب
├── products.html         # المنتجات الرقمية والخطط
├── membership.html       # خطط العضويات الخاصة
├── admin.html            # لوحة تحكم الإدارة
└── assets/
    ├── css/
    │   └── style.css
    └── js/
        └── main.js
